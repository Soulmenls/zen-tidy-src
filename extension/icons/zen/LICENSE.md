# Folder icons

These 87 icons are [Ionicons](https://ionic.io/ionicons) by Ionic, as shipped in Zen Browser's
folder icon picker (`src/browser/themes/shared/zen-icons/common/selectable/`). Zen credits them as
"used under the MIT License"; each file keeps Zen's MPL-2.0 notice. Only the fill was changed (to solid
black, because the popup uses the files as CSS masks). Regenerate with `scripts/import-icons.mjs`.
